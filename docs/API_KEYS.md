# API 키 연결 안내

키를 넣기 전에는 무료 지도(OpenStreetMap)와 무료·가짜 데이터로 동작하고,
`.env.local`에 Google 키를 넣으면 아래 기능이 **자동으로 Google로 바뀝니다**.

| 기능 | 키 없을 때 | Google 키 있을 때 |
|---|---|---|
| 지도 표시 | OpenStreetMap | Google 지도 |
| 장소 이름 검색 | Photon (OSM) | Places API (New) – 텍스트 검색 |
| 지도에서 누른 위치 이름 | Photon 역지오코딩 | Places 주변 검색 + Geocoding API |
| 주변 유명한 곳 | 위키백과 위치 검색 | Places 주변 검색 (인기순) |
| 맛집·카페·관광 별점 추천 | 가짜 데이터 | Places 주변 검색 (별점·리뷰 수) |
| 이동시간·경로 | 거리로 추정 | 아래 "경로 API" 표 참고 |

### 경로 API — 나라·이동수단별로 쓰는 곳

| | 도보 | 대중교통 | 택시 |
|---|---|---|---|
| 한국 | **TMAP** 키 필요 (없으면 거리 추정) | **ODsay** 키 있으면 ODsay (요금·환승 포함), 없으면 **Google Routes** | 거리 추정 |
| 일본 | **Google Routes** | 거리 추정 (Google이 일본 대중교통 길찾기를 제공하지 않음) | **Google Routes** 시간 + 요금 추정 |
| 베트남·대만·태국·인도네시아·필리핀·싱가포르·홍콩·말레이시아 | **Google Routes** | **Google Routes** (요금은 오면 실제, 없으면 추정) | **Google Routes** 시간 + 요금 추정 |

- Google은 한국에서 도보·자동차 길찾기를 제공하지 않아서, 한국 도보는 TMAP으로 받습니다.
- 경로 API가 없거나 실패한 구간은 거리로 계산한 값을 쓰고, 화면에 **"추정"**이라고 표시합니다.
- 방문 순서는 거리 추정으로 먼저 정하고, 정해진 순서의 구간만 실제로 길찾기를 부릅니다 (호출 수를 줄이기 위해).

## 1. Google Cloud 프로젝트 만들기

1. https://console.cloud.google.com 에 Google 계정으로 로그인합니다.
2. 위쪽 프로젝트 선택 메뉴에서 **새 프로젝트**를 만듭니다. (예: `trip-route-planner`)

## 2. 결제 계정 연결

- Google Maps Platform은 **결제 계정을 연결해야** 키가 동작합니다.
- API마다 매월 무료 사용량이 있어서 개발 중 혼자 테스트하는 정도는 보통 무료 범위 안에 들어갑니다.
  정확한 무료 한도와 요금은 바뀔 수 있으니 공식 요금 페이지를 확인하세요:
  https://mapsplatform.google.com/pricing/
- **예산 알림**을 꼭 걸어 두세요: 콘솔 → 결제 → 예산 및 알림 → 예산 만들기 (예: 월 1만 원, 50%·90%·100%에서 메일 알림)

## 3. 필요한 API 켜기

콘솔 → **API 및 서비스 → 라이브러리**에서 아래 3개를 검색해 각각 **사용 설정**합니다.

1. **Maps JavaScript API** – 지도 표시
2. **Places API (New)** – 장소 검색, 주변 장소, 별점  
   ※ 이름이 비슷한 예전 "Places API"가 아니라 **(New)**가 붙은 것을 켜야 합니다.
3. **Geocoding API** – 지도에서 누른 위치의 주소
4. **Routes API** – 이동시간·경로 (한국 대중교통, 일본 도보·택시)

## 4. API 키 만들기

콘솔 → **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**

## 5. 키 사용처 제한 (중요)

이 앱은 키를 브라우저에서 바로 쓰기 때문에 **누구나 키를 볼 수 있습니다.**
남이 가져가 쓰지 못하도록 반드시 제한을 걸어 주세요. 만든 키를 눌러 편집 화면에서:

- **애플리케이션 제한사항**: `웹사이트` 선택 → 웹사이트 제한사항에 추가
  - `http://localhost:5173/*`
  - (나중에 배포하면 그 주소도 추가, 예: `https://내도메인/*`)
- **API 제한사항**: `키 제한` 선택 → 위 4개 API만 체크
  (Maps JavaScript API, Places API (New), Geocoding API, Routes API)

제한을 바꾼 뒤 적용까지 몇 분 걸릴 수 있습니다.

### (권장) 하루 사용량 상한 걸기

콘솔 → API 및 서비스 → **Places API (New)** → **할당량 및 시스템 한도**에서
하루 요청 수를 적당히(예: 1,000건) 낮춰 두면 실수로 요금이 많이 나오는 것을 막을 수 있습니다.

## 6. 앱에 키 넣기

1. 프로젝트 폴더의 `.env.example` 파일을 복사해서 이름을 **`.env.local`**로 바꿉니다.
2. `.env.local`을 열어 `VITE_GOOGLE_MAPS_API_KEY=` 뒤에 키를 붙여넣고 저장합니다.
   ```
   VITE_GOOGLE_MAPS_API_KEY=AIza...여기에 키
   ```
3. 개발 서버를 **껐다가 다시 켭니다** (설정 파일은 서버를 켤 때만 읽습니다).
   ```
   npm run dev
   ```

- `.env.local`은 git에 올라가지 않도록 되어 있습니다.
- 키를 채팅·메신저·이메일 등에 붙여넣지 마세요. 키가 노출되면 콘솔에서 **키 다시 만들기**로 바꾸면 됩니다.

## 7. 연결 확인

- 지도 오른쪽 아래에 **Google** 로고가 보이면 지도 연결 성공입니다.
- 장소 단계에서 검색했을 때 결과가 나오고, 결과 화면 "주변 추천" 아래에
  "Google 지도의 별점·리뷰 수 기준입니다."라고 나오면 장소 API까지 연결된 것입니다.

## 문제가 생기면

브라우저 개발자 도구(F12) → Console 탭의 오류 메시지를 보면 원인을 알 수 있습니다.

| 오류 메시지에 보이는 말 | 원인 | 해결 |
|---|---|---|
| `ApiNotActivatedMapError` | Maps JavaScript API가 꺼져 있음 | 3단계에서 사용 설정 |
| `RefererNotAllowedMapError` | 웹사이트 제한에 지금 주소가 없음 | 5단계에 `http://localhost:5173/*` 추가 |
| `BillingNotEnabledMapError` | 결제 계정 미연결 | 2단계 |
| `InvalidKeyMapError` | 키를 잘못 붙여넣음 | `.env.local` 값 확인 후 서버 재시작 |
| Places 요청이 `403` / `PERMISSION_DENIED` | Places API (New)가 꺼져 있거나 키의 API 제한에 빠짐 | 3·5단계 확인 |

## 8. (선택) 한국 대중교통 — ODsay

요금·환승 횟수까지 정확히 받으려면 ODsay 키를 넣으세요. 없으면 Google 대중교통(요금은 추정)을 씁니다.

1. https://lab.odsay.com 에 가입하고 로그인합니다.
2. 애플리케이션(키) 등록에서 **Web** 플랫폼으로 키를 만들고, 사용할 주소(URI)에 `http://localhost:5173`을 등록합니다.
3. 발급된 키를 `.env.local`의 `VITE_ODSAY_API_KEY=` 뒤에 넣고 개발 서버를 다시 켭니다.

무료 사용량은 하루 호출 수 제한이 있습니다. 자세한 한도는 ODsay LAB 사이트에서 확인하세요.

## 9. (선택) 한국 도보 — TMAP

한국에서 실제 보행 경로(도보 시간, 지도 위 길 모양)를 받으려면 TMAP 키가 필요합니다.

1. https://openapi.sk.com 에 가입하고 로그인합니다.
2. 앱(프로젝트)을 만들고 **TMAP API** 상품을 사용 신청합니다 (무료 요금제가 있습니다).
3. 발급된 **App Key**를 `.env.local`의 `VITE_TMAP_APP_KEY=` 뒤에 넣고 개발 서버를 다시 켭니다.

## 경로 관련 문제가 생기면

- 화면 아래 "이동시간 기준: …" 문구에서 지금 어떤 서비스를 쓰는지 확인할 수 있습니다.
- 키를 넣었는데도 "추정"으로만 나오면 F12 → Network 탭에서 `routes.googleapis.com`, `api.odsay.com`, `apis.openapi.sk.com` 요청의 응답을 확인하세요.
  - Google `403`: 키의 API 제한에 Routes API가 빠졌거나 사용 설정이 안 됨
  - ODsay `ApiKeyAuthFailed`: 등록한 URI와 지금 주소가 다름
  - TMAP `401`/`403`: App Key 오타, TMAP 상품 미신청

## 요금 참고 — 이 앱이 Google을 부르는 때

- 장소 단계: 검색어 입력을 멈출 때마다 1회, 지도를 누를 때마다 2회, 위치가 바뀔 때 주변 유명한 곳 1회
- 결과 화면: 방문지마다 맛집·카페·관광 3회 (**별점·리뷰 수는 요금이 높은 등급**의 데이터)
- 결과 화면: 이동 구간마다 길찾기 (한국 1회, 일본 2회) — 순서·장소가 바뀌어 새 구간이 생길 때만
- 같은 장소는 다시 부르지 않도록 앱 안에서 기억(캐시)합니다. 새로고침하면 다시 부릅니다.
